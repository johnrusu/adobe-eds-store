# Columns Block

## Overview

The Columns block provides a responsive multi-column content layout. It detects
the number of cells in the first row, adds a matching layout class, and marks
image-only cells so CSS can size and align media independently from text.

## Integration

### Authoring Structure

The component model supports between one and six columns. Each block contains
one or more rows, with text or image components in each cell.

### Block Configuration

| Configuration Key | Type | Default | Description | Required | Side Effects |
|---|---|---:|---|---|---|
| `columns` | number | `2` | Number of authored columns in the component model. | No | Determines the row structure generated by the authoring UI. |

The runtime does not use `readBlockConfig()`; it derives the actual column count
from the delivered markup.

### URL Parameters, Storage, and Events

The block does not use URL parameters, browser storage, or custom events.

## Behavior Patterns

- Adds `columns-{n}-cols` based on the first row.
- Adds `.columns-img-col` when a column contains only one picture.
- Supports mixed text, buttons, and image content.
- Mobile stacking and desktop column widths are controlled by `columns.css`.

### Error Handling

No network requests are made. The block expects at least one row; empty block
markup does not satisfy its authoring contract.
