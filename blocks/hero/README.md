# Hero Block

## Overview

The Hero block presents a primary page image and heading. Its delivered markup
is already semantic, so the block is styled entirely with CSS and requires no
runtime JavaScript transformation.

## Integration

### Authoring Structure

| Field | Type | Required | Description |
|---|---|---|---|
| `image` | image reference | No | Main hero artwork. |
| `alt` | string | No | Accessible alternative text for the image. |
| `text` | string | No | Hero heading content. |

### Block Configuration

The block has no key/value configuration.

### URL Parameters, Storage, and Events

The block does not read URL parameters, access browser storage, or interact with
the Commerce event bus.

## Behavior Patterns

- Uses the authored picture sources generated by AEM.
- Keeps the heading and image responsive through `hero.css`.
- Relies on AEM image optimization for authored media.
- Preserves normal heading semantics and image alternative text.

### Error Handling

There are no network calls in block code. Missing optional image or text fields
simply result in reduced hero content. Authors should provide meaningful alt
text whenever the image conveys information.
